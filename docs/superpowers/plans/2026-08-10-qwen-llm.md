# Qwen LLM Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an Alibaba Cloud Model Studio (DashScope) Qwen backend for the conversation and planning LLM through a reusable OpenAI-compatible adapter.

**Architecture:** Extract `OpenAICompatibleAdapter` for providers implementing the OpenAI Chat Completions contract. Keep OpenAI and Qwen as configuration choices of that adapter, while Gemini retains its native adapter. Extend the central config and LLM factory, then make Qwen configuration available in Compose and README; do not change planner, executor, or embedding layers.

**Tech Stack:** Python 3.11+, OpenAI Python SDK 1.58.1, pytest, Docker Compose.

## Global Constraints

- Only `AGENT_LLM_BACKEND=qwen` selects this provider.
- `DASHSCOPE_API_KEY` is required and must never be logged or returned.
- Default model: `qwen-plus`.
- Default endpoint: `https://dashscope.aliyuncs.com/compatible-mode/v1`.
- `DASHSCOPE_BASE_URL` supports a different region or workspace.
- No embeddings, native DashScope SDK, streaming, tool calls, web search, thinking mode, multimodal inputs, or retries.

class FakeCompletions:
    def __init__(self, text):
        self.text = text
        self.calls = []

    def create(self, **kwargs):
        self.calls.append(kwargs)
        message = type("Message", (), {"content": self.text})()
        choice = type("Choice", (), {"message": message})()
        return type("Response", (), {"choices": [choice]})()

class FakeQwenClient:
    def __init__(self, text):
        self.chat = type("Chat", (), {"completions": FakeCompletions(text)})()

def test_compatible_adapter_uses_chat_contract(monkeypatch):
    monkeypatch.setenv("DASHSCOPE_API_KEY", "dummy-key")
    client = FakeQwenClient(text="first. second.")
    from src.agent.llm_compatible import OpenAICompatibleAdapter

    assert OpenAICompatibleAdapter(model="qwen-test", api_key_env="DASHSCOPE_API_KEY", base_url="https://dashscope.test/v1", client=client).plan("prompt") == ["echo: first", "echo: second"]
    assert client.chat.completions.calls == [{"model": "qwen-test", "messages": [{"role": "user", "content": "prompt"}], "max_tokens": 512}]
