# OpenAI-Compatible LLM Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a generic OpenAI-compatible backend for the conversation and planning LLM, with Qwen as a DashScope convenience preset.

**Architecture:** Use `OpenAICompatibleAdapter` for providers implementing the OpenAI Chat Completions contract. Expose both `openai-compatible` (arbitrary provider settings) and `qwen` (DashScope preset) in the factory, while Gemini retains its native adapter. Extend central config, Compose, tests, and README; do not change planner, executor, or embedding layers.

**Tech Stack:** Python 3.11+, OpenAI Python SDK 1.58.1, pytest, Docker Compose.

## Global Constraints

- `AGENT_LLM_BACKEND=openai-compatible` selects arbitrary compatible providers.
- `AGENT_LLM_BACKEND=qwen` selects the DashScope preset.
- Configured API keys are required and must never be logged or returned.
- Generic backend variables are `OPENAI_COMPATIBLE_API_KEY`, `OPENAI_COMPATIBLE_BASE_URL`, and `OPENAI_COMPATIBLE_MODEL`.
- Default model: `qwen-plus`.
- Default endpoint: `https://dashscope.aliyuncs.com/compatible-mode/v1`.
- `DASHSCOPE_BASE_URL` supports a different region or workspace.
- No embeddings, native DashScope SDK, streaming, tool calls, web search, thinking mode, multimodal inputs, or retries.

class FakeCompletions:
    def __init__(self, text):
        self.text = text
        self.calls = []

    def create(self, **kwargs):
        self.calls.append(kwargs)
        message = type("Message", (), {"content": self.text})()
        choice = type("Choice", (), {"message": message})()
        return type("Response", (), {"choices": [choice]})()

class FakeQwenClient:
    def __init__(self, text):
        self.chat = type("Chat", (), {"completions": FakeCompletions(text)})()

def test_compatible_adapter_uses_chat_contract(monkeypatch):
