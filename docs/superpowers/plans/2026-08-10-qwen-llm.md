# Qwen LLM Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an Alibaba Cloud Model Studio (DashScope) Qwen backend for the conversation and planning LLM.

**Architecture:** Add `QwenAdapter`, using the existing OpenAI SDK against DashScope's compatible Chat Completions endpoint. Extend the central config and LLM factory, then make configuration available in Compose and README; do not change planner, executor, or embedding layers.

**Tech Stack:** Python 3.11+, OpenAI Python SDK 1.58.1, pytest, Docker Compose.

## Global Constraints

- Only `AGENT_LLM_BACKEND=qwen` selects this provider.
- `DASHSCOPE_API_KEY` is required and must never be logged or returned.
- Default model: `qwen-plus`.
- Default endpoint: `https://dashscope.aliyuncs.com/compatible-mode/v1`.
- `DASHSCOPE_BASE_URL` supports a different region or workspace.
- No embeddings, native DashScope SDK, streaming, tool calls, web search, thinking mode, multimodal inputs, or retries.
